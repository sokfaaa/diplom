## 📁 Структура репозитория

| Имя файла | Назначение |
|-----------|------------|
| `app_version2.py` | **Основное веб-приложение** на Streamlit, реализующее 10-шаговый интерактивный цикл: загрузка данных, EDA, обработка пропусков, рекомендация метода, балансировка, визуализация, обучение ML-моделей, сравнение методов и экспорт результатов. Главная точка входа для пользователя. |
| `app.py` | Предыдущая (устаревшая) версия приложения, сохранённая для истории. |
| `knn_recommender.py` | **Модуль kNN-рекомендателя** — класс `KNNSamplerRecommender`. Обучается на базе знаний из 200 реальных датасетов и рекомендует оптимальный алгоритм балансировки для нового датасета на основе метапризнаков. Возвращает список ближайших соседей, уверенность и альтернативы. |
| `train_metamodel.py` | Обучение **классической метамодели** (RandomForest, LightGBM, XGBoost и др.) с подбором гиперпараметров через Optuna. Используется для сравнения с kNN-подходом. |
| `evaluate_metamodel.py` | Оценка качества обученной метамодели (Accuracy, F1-macro, Balanced Accuracy) на кросс-валидации или отложенной выборке. |
| `find_optimal_k.py` | Поиск оптимального числа соседей `k` для kNN-рекомендателя по критерию максимизации LOO-Accuracy. Генерирует график `optimal_k_plot.png`. |
| `compute_metafeatures.py` | Вычисление расширенного набора **метапризнаков** (стандартные из `pymfe` + кастомные: IR_variance, minority_isolation, CV и др.) для описания структуры многоклассового дисбаланса. |
| `add_metafeatures.py` | Присоединение вычисленных метапризнаков к существующим датасетам для формирования обучающей выборки метамодели. |
| `dataset_generator.py` | Генератор **синтетических датасетов** с контролируемыми параметрами (число классов, IR, признаков, шум) на основе функций scikit-learn. Создано 591 датасет для предварительной верификации. |
| `benchmark_samplers.py` | Проведение **сравнительного эксперимента** — тестирование 13 алгоритмов балансировки на всех датасетах (реальных и синтетических). Сохраняет таблицы метрик (F1-macro, Balanced Accuracy, G-mean) и приростов. |
| `clean_datasets.py` | Предобработка реальных датасетов: удаление пропусков, фильтрация по числу классов/признаков, отсев выбросов. |
| `fetch_multiclass_real.py` | Дополнительный скрипт для загрузки **многоклассовых** датасетов (уточняет основной). |
| `select_datasets.py` | Отбор датасетов из загруженного пула по заданным критериям (IR, число классов, размерность) для итоговой экспериментальной базы (200 датасетов). |
| `analis.py` | Статистический анализ результатов: построение графиков, корреляционный анализ, тест Колмогорова–Смирнова, визуализация распределений метапризнаков и эффективности алгоритмов. |
